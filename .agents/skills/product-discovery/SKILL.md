# Product Discovery Skill

## Purpose
Systematically discover, validate, and document customer problems, target personas, and value propositions for the Flatmate platform, with specific focus on initial launch markets (Thiruvananthapuram, Kerala, India).

## When to Use It
- During Workflow A (Ideation) and initial product exploration.
- When evaluating new feature concepts, user modalities, or target user segments.
- Whenever user feedback suggests a disconnect between platform capability and real-world flatmate discovery friction.

## Required Inputs
- Initial product vision and core pillars (Compatibility, Trust & Safety, Person-First Discovery).
- Target audience profile (college students, Technopark/Infopark IT professionals, relocators).
- Geographic and cultural constraints for Thiruvananthapuram, Kerala.

## Step-by-Step Procedure
1. **Define Problem Hypotheses**: Frame the core user problems across the four discovery modalities (room available, looking for room, relocator, compatible person first).
2. **Conduct User & Market Empathy Mapping**: Detail pain points with current alternatives (broker commissions, invasive landlord questions, unvetted Facebook/WhatsApp groups, lifestyle clashes like sleep schedules, dietary habits, cleanliness standards).
3. **Formulate Value Proposition Canvas**: Map customer jobs, pains, and gains against Flatmate products, pain relievers, and gain creators.
4. **Draft Problem Statement & Vision**: Document the validated problem statement in `docs/product/problem-statement.md`.
5. **Scope MVP Hypotheses**: Define falsifiable hypotheses for MVP validation (e.g., "70% of Technopark professionals prefer matching on daily routine compatibility before viewing flat listings").

## Expected Outputs
- `docs/product/problem-statement.md`
- `docs/product/value-proposition.md`
- Initial MVP hypothesis list in `docs/product/mvp-scope.md`.

## Quality Checklist
- [ ] Addresses all 4 core user modalities.
- [ ] Explicitly considers Kerala / Trivandrum regional context (local transit hubs, college campuses, Technopark).
- [ ] Separates accommodation search from person-to-person compatibility matching.
- [ ] Establishes measurable validation criteria.
